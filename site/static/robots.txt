# Everything here is meant to be found, cited and linked to. There is no
# Disallow.
#
# The site has no private area, no account, and no search-result or filter URLs
# that multiply into a crawl trap: every address is a canonical citation
# (`/scriptura/{osis}/{chapter}`, `/catechismus/{n}`, …), and an address that is
# not one gets a real 404 from the edge worker rather than the shell with a 200.
# So there is nothing here a crawler can reach that we would rather it did not
# spend a request on.
#
# This file said `Disallow: /` until launch, to keep the verification-only
# Cloudflare hostname out of the index. The other half of that block lived in
# site/static/_headers as `X-Robots-Tag: noindex, nofollow`, and the two were
# always to be undone together — noted here because a robots.txt that permits
# everything is not by itself evidence that the header does too. `Disallow`
# governs the fetch; the header governs the indexing.

User-agent: *
Disallow:

# The site is one SPA shell: every address returns the same document, and the
# cross-reference links between texts are written by JavaScript. So the corpus
# is not discoverable by following links unless the crawler renders, and the
# sitemap is the only flat statement of the ~5,800 canonical citations.
# Generated from the same route manifest the edge worker validates against
# (site/scripts/sitemap.mjs), so it cannot advertise an address that 404s.
Sitemap: https://glossacatholica.org/sitemap.xml
